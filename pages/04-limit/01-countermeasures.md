# Контрмеры как перестройка контура

| мера | что она делает с контуром |
| --- | --- |
| **Ограничение запросов на входах** | Ограничивает амплитуду входного воздействия |
| **Автоотключение повторов** | Размыкает петлю в момент, когда она включается |
| **Бюджет повторов** | Ограничивает долю повторов в потоке клиента |
| **Плавный возврат нагрузки** | Управление по траектории: система «остыла», кэши пусты |
| **LIFO и приоритеты заказов** | Уменьшают долю холостой работы |
| **Режим деградации** | Отключает некритичные функции; согласуется с бизнесом |
| **Учения с отключением ЦОД** | Измеряют реальный запас мощности, а не расчётную цифру |
