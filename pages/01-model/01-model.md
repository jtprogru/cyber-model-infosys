# Контур управления в терминах ИС

| элемент контура | чем представлен в ИС | пример |
| --- | --- | --- |
| **Объект управления** | Сервис и его зависимости | Приложение, база данных, сеть |
| **Уставка** | Целевой уровень качества | SLO: 99,9 % ответов за 30 дней |
| **Возмущение** | Внешние воздействия | Всплеск трафика, обрыв сети, отказ БД |
| **Датчики** | Сбор телеметрии | Метрики, трассировки, журналы |
| **Сравнение и анализ** | Вычисление SLI и отклонения | Мониторинг, правила оповещений |
| **Регулятор** | Выбор воздействия | Автоскейлер, лимиты, дежурный |
| **Исполнительные устройства** | Изменение состояния объекта | Оркестратор, балансировщик, релизы |
